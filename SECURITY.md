# Security Policy

## Supported Versions

The following versions of **bunnynet-lib** currently receive security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

Only the latest major version receives security fixes.

---

## Reporting a Vulnerability

If you discover a security vulnerability in this project, you can report it in one of the following ways:

### 1. GitHub Issue (Preferred for non-sensitive reports)

You may open a GitHub issue and clearly describe the vulnerability.

Please include:

* A clear description of the vulnerability
* Steps to reproduce the issue
* Potential impact
* Suggested fix (if available)

Repository issues page:
https://github.com/range79/bunnynet-lib/issues

---

### 2. Private Email (Recommended for sensitive vulnerabilities)

If the vulnerability could expose user data, credentials, or other sensitive information, please report it privately.

Email:
[darkrange6@gmail.com](mailto:darkrange6@gmail.com)

---

## Response Time

* Initial response: **within 48 hours**
* Verified issues will be fixed in the next security release.

---

## Disclosure Policy

This project follows **responsible disclosure**:

* Vulnerabilities may remain private until a fix is available.
* Once fixed, the issue may be publicly documented in release notes.

---

## Scope

This policy covers security issues related to:

* Bunny.net API integration
* File upload and download operations
* HTTP client behavior
* Authentication and API key handling

---

Thank you for helping improve the security of this project.
