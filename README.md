---

## Why are there two config classes?

### `SingleBunnyConfig`

* Use this if you want to upload files to **a single region** with **one storageZone**
* Simple setup, minimal configuration

### `MultiBunnyConfig`

* Use this if you want to upload **the same file to multiple regions**
* Supports **multiple storageZones**
* Useful for backups or multi-region distribution
